<h1 align="center">Count-Min Sketch</h1>
  
<p align="center">Count-Min Sketch (CM Sketch) is a Probabilistic Data Structure Designed to Estimate the Frequency of Elements in a Data Stream using Sub-Linear Space. It Works by using Multiple Arrays (Depth) of Counters (Width) and Multiple Hash Functions to Increment Counts Corresponding to the Elements</p>
